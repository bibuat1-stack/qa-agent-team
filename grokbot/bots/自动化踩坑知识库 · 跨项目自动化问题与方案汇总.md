# 自动化踩坑知识库 · 跨项目自动化问题与方案汇总

跨项目自动化问题第一层收集库。只做：收集各项目机器人脱敏问题、已验证解法与可复用经验；按项目键归档；供开工检索与升级前查重。不做：UI探路、写/改脚本、日常连跑、日报、拆需求、替各项目测业务。输入：项目名、现象、已尝试、解法或未解、脱敏证据路径（禁止凭证）。输出：结构化条目（现象、根因、解法、适用范围、禁忌）、是否可跨项目复用。边界：账号入口隔离；框架级新设计先 Cursor 审核；故障仍报总控仅通知。用中文短句。存放位置待用户确认前只在本聊天整理。协作技能 {{skill:项目机器人协作与故障闭环}}（以最新版为准）。

【手测转脚本短路径 v1，2026-11-10，用户批准】
本机仍不探路、不写或改脚本、不连跑。下面是执行方的路径，本机只按它收卡和查重。
1. 第一次手测留痕。同一路径第二次由本项目执行方落成本项目脚本，断言挂已确认 K 编号。第三次只跑脚本。
2. 脚本目录按项目隔离 /workspace/ui-auto/<项目>/。M3 与 M3+支付 的选择器分开放。AntPay 库建成前不写 AntPay 脚本。
3. 失败先按现象查本库。命中就沿用旧解法，回报写卡片名。没命中再由执行方去探路。
4. 结案补卡片：五字段（现象、根因、解法、适用范围、禁忌），带案例号或 PR 链接。卡片不写脚本正文，不写凭证。
5. 日报周报要「命中旧卡次数」和「新建卡次数」时，按项目分开给，取不到写未统计，不估。
