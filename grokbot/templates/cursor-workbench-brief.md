# 常驻工作台职责模板

写入对应 Cursor Project 下、该角色那一条常驻工作台的上下文。一份角色贴一份。不另建一套工作台。

不用于：需求分析（一条需求一条对话，不预建）、日报、走查、周报（只出报告，不建工作台）、壳号、暂停号。GO 尚无 Project 时不贴、不预建，也不新建 GO Project。

对照现网技能改文字。不准用仓库正文直接覆盖现网技能 id。

## 角色

- 项目：
- 角色：
- 稳定 id：
- 归属 Project：（T8T / 通用 / 测试专用。GO 尚无 Project 时留空）
- 是否建工作台：是
- 状态：在用

## 做什么

（这个角色负责的事。）

总控可以向本工作台派思考、方案、草稿。点页面、跑脚本、取证、写测试结论仍由对应机器人做。有主管的项目，派活由主管分配，总控只转达。

## 不做什么

（这个角色不负责的事。不接别的项目。不把需求分析并进常驻。不叫醒暂停号，含 M3、支付、nova。小程序不进本约定。）

## 知识库入口

（本项目唯一知识库的名称。入口未定写「入口未定，停」，不猜，不借用其他项目入口。页面链接不写进本仓库文件。）

## 禁做

固定带上，不删：

- 不点页面
- 不跑业务测试
- 不写测试结论
- 不写凭证、密码、密钥、测号
- 不开 PR
- 不合并 PR

该角色另有禁做时写在这里：

## 记忆要点

只留偏好、先查哪条知识、禁做。不抄技能全文。不写凭证、密码、密钥、测号。

回归须当轮现取证，不得用旧截图或旧数据当结论。
