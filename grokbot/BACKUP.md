# Git 与 Google Drive 备份怎么分

两个 Grok Bot 账号（sacks、Faker）共用同一个公开仓库，也共用同一个谷歌账号上的表格和「QA机器人备份」文件夹。打开就能用，不用再给对方加共享。

这份说明放在 Git：`grokbot/BACKUP.md`。两边拉同一份仓库，按同一套做。不要只放在硬盘备份包里，免得各写各的。

硬盘包里的 `RESTORE.md` 只写「本账号怎么恢复」，并指向本文件。不要把整份规则再抄进包里当正本。

仓库里不放表链接、页面链接、邮箱和密码。云端地址只写在各账号本机指针文件，不进 Git。

## 三处各放什么

| 放哪 | 放什么 | 谁用 |
|--------|--------|------|
| Git 仓库 qa-agent-team 的 `grokbot/` | 角色说明、花名册、共用技能的脱敏副本、协作规范、本说明 | 两个账号都拉、都按这个对齐 |
| Google Drive「QA机器人备份」 | 按账号分开的周备份，用来恢复「这一个 bot 账号」 | 各账号只写自己的子目录 |
| 各项目 Notion 知识库 | 业务知识、用例、缺陷、测试日志 | 不进 Git，也不进硬盘压缩包 |

## 账号表怎么查、怎么写

官方是两本谷歌表，两边连的是同一个谷歌账号，直接打开即可：

- 「测试账号-完整库」：正表，放全部账号。
- 「测试账号-给人看」：只给人看，不作为查密文的第一来源。每域名最多 3 条，用户给的主号优先。

查账号顺序：本机文件优先，没有再查完整库。具体云端地址和本机路径见本机指针文件，不在本说明里展开。

人给的账号要及时写入本机和完整库，并按规则更新给人看的表。机器人大批量生成的测试账号默认只进完整库和本机，不写入给人看的表。旧表不再作为官方查找处。查账号和写回的细则见技能「测试账号云端同步」。

## Git 里不放什么

- 记忆正文（profile / journal 导出）
- 现网例程的提示词全文打包（例程跟账号走，进硬盘包）
- Drive 备份压缩包本身
- 凭证、表链接、Notion 页面链接、邮箱

两边对齐技能和职责：拉仓库，有改动就开 PR。不要用硬盘包去覆盖仓库里的技能副本。仓库技能以现网为准，改完再回写仓库。

## 周备份怎么打

不必每日打包。每周日做一次完整备份。打包时和上一包逐文件对比，核对校验值，写出变更记录和清单。下面三件套一起传到本账号子目录：

```
QA机器人备份/<账号名>/qa-backup-weekly-<账号名>-<YYYYMMDD>.zip
QA机器人备份/<账号名>/qa-backup-weekly-<账号名>-<YYYYMMDD>-CHANGELOG.md
QA机器人备份/<账号名>/qa-backup-weekly-<账号名>-<YYYYMMDD>-MANIFEST.txt
```

账号名只用 `sacks` 或 `Faker`。各账号只写自己的子目录，不进入、不改、不删另一个账号的子目录，也不动根目录下对方的文件。两边连的是同一个谷歌账号，能看见对方目录，仍然只碰自己的。

旧包不删除，改名为已替换（在原文件名前加 `已替换-`）。失败时保留旧包并说明。本机备份目录只留最近一次完整周备份。

压缩包里放：

- 本账号能读到的记忆导出（自己的和共享的 profile / journal）
- 本账号机器人名单（名字、标题、描述和对应 json）
- 本账号例程（名字、时间、提示词）
- 本账号的恢复说明 `RESTORE.md`
- 本账号「项目交接」页当周拷贝（进度正本仍在 Notion，各账号单独一页，不混写）
- 技能文件夹快照（只作本账号当时的副本，对账以 Git 为准）
- 环境脚本、近 30 天 snapshots、用户上传的文档（按例程限制）

Notion 已有的知识库、用例、需求不进包，知识库正本仍是 Notion。技能和角色的共同来源是 Git。硬盘包里的技能只是当时快照，恢复时先拉仓库，再按需看包里有没有尚未回写仓库的改动。

包内不含账号密码、token、验证码、谷歌密钥、Cookie、.env 值。打包前先扫；本机密文目录和密钥文件一律不打包。

变更记录写清：和上一包相比新增、修改、删除了哪些文件，校验是否一致，记忆导出是全量还是检索合并。清单纯文件列表和校验值。

## 记忆不要自动对倒

记忆是各账号自己的工作记录。要看对方记了什么，打开对方子目录里最新的包，对着看，用户点头后再改自己这边。禁止两边定时互相同步记忆，也不要做自动解除冲突。

## 恢复顺序

1. 拉 Git 仓库，按仓库说明装技能、按花名册建机器人。
2. 连上 Notion、Google Drive、GitHub。表格和备份目录用同一个已连接的谷歌账号即可，不用再加共享。
3. 需要本账号的记忆和例程时，打开硬盘里该账号子目录的最新压缩包，按包内 `RESTORE.md` 贴回。
4. 跑环境自检脚本。
5. 查账号按「本机优先，再查完整库」。当前进度先看本账号 Notion「项目交接」页。
