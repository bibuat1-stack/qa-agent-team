# 缺陷复现简报（机器人优化版）

报告不全、偶发、或环境相关时，先证明最小可观察失败，再诊断。

## 步骤

1. **记现象**：确切错误/错误输出、时间、路由或命令、已知最小输入。日志脱敏。二手描述标未证实
2. **记环境**：能查到的才写（仓库/提交、运行时、OS、锁文件、是否本地/测试/预发/生产）。不猜凭证与生产配置
3. **拆期望与实际**：两句可观察陈述，不把猜因写进去
4. **缩小**：按报告路径走，再逐项去掉无关数据与步骤。保留仍失败的最小夹具。失败消失则恢复最后去掉的条件并记下
5. **可重复**：安全时至少跑两次。偶发则写频率与窗口，不谎称必现
6. **停在修复前**：简报是交付物。建简报期间不改实现代码，以免毁掉证据

视觉 UI 复现可接 [reproduce-bug-report](sand-workflow:reproduce-bug-report)。系统诊断接 [diagnosing-bugs](sand-workflow:diagnosing-bugs)。

## 输出

短句中文：

```text
目标与提交：
环境：
期望：
实际：
最小复现步骤/命令：
重复：必现 / 约 N/M
证据路径：
未证实：
下一步：一条诊断动作
```
