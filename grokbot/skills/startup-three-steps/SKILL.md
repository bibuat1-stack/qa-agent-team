花名册该项目状态是暂停（含 nova）时，本技能结束：不开测、不写库、不建工作台。技能存在不等于暂停项目开工。日报、周报不走本技能。

本技能只负责开始做之前的环境、读库和三句复述。不用于：交接六项和验收状态（见 [派工与接单](sand-workflow:skill-1794468373416)）、交活前核证据（见 [测试证据](sand-workflow:skill-1794740098289)）、出报告和释放（见 [批次收尾](sand-workflow:skill-1794469727907)）。

用户说重新测试或回归时，必须当轮现取证后再下结论，见 [测试证据](sand-workflow:skill-1794740098289)「重新测试或回归」。这里不另写判定。

## 停手（先于步骤）
1. 花名册该项目是暂停：结束。
2. 整批没有验收依据才停。范围、验收依据、禁做三项有空：停，用下面固定问句，不问就不开测。
   - 「这次测的范围是哪一段？」
   - 「验收依据是哪条已确认知识点或哪份资料？没有就写无依据，停。」
   - 「哪些不能做？」
   整批没有依据是瞎测。单条只有待确认或待核实，可以先跑，只能记已跑待确认；能不能先跑见协作「用例分批放行」，这里不重写。单条待核实先跑，是为了留下证据，等依据到了再判。
3. GO 在用户给出本项目唯一知识库入口之前：第一句写「GO 入口未定，停」，不猜链接、不扫别的库。

## 第一步：环境
原样运行 `/workspace/qa/qa-ready.sh`（需要体检时才加 `--health`）。记录退出码。退出码不是 0：停，报告退出码和相关日志路径，不自动重试，不把脚本内部写成步骤。命令输出超过 80 行时，写入 `/workspace/qa/runs/<当次时间>/`，回复只留路径、退出码和最后 80 行。

先认清当前是哪台机器、什么系统、这台上已有什么，再选最合适且效率最高的方式。不能只说「本地」，要写机器标识。Linux 云电脑和 Windows 本机不能混用路径和命令；macOS 或其他架构也先探再选，不要套现成路径。同一账号下的不同电脑要换机器重新探。各台的 Node、CLI、浏览器版本不必跨机器对齐。登录态和调试端口只属于当前这台机器，不能跨机器、跨系统用。8791 是云电脑桌面浏览器的问题，不要套到用户电脑。用户电脑本身需要的 VPN 或系统代理不要盲目关掉。有头启动按系统分开：Windows 本机有真实桌面，但仍不抢、不驱动用户正在用的系统 Chrome；Linux 云电脑用 `/workspace/qa/bin/open_direct_headed.py` 拉起后再 attach。Linux 上启动 Chrome for Testing 常需要 `--no-sandbox`，Windows 一般不这样套。环境配置要写明机器标识、系统、版本和路径，不要只写「环境已就绪」。用前先探，路径和版本记在本机，不抄到别的机器。上面的 `qa-ready.sh` 只用于 Linux 云电脑。Windows 本机不要套这条路径。

## 第二步：只读本项目知识
1. 只开本项目唯一知识库入口。不去别的项目库找账号、入口或规则。缺入口、缺上一棒交接物（任务清单／用例／缺陷单／留痕路径），先补齐再开测。
2. 测号查找按「测试账号云端同步」：先本机，没有再查谷歌表。聊天不写密码。三处没有或不全时：还没有账密就停并说明，不得用别处账密登录后不管；用户当轮给了账密，或本轮已经登录成功，立刻按该技能写回三处并读回，再继续测。
3. 读库怎么分栏、少读和当天复用，按 [测试记忆-开工](sand-workflow:skill-1793821780103)，这里不抄条件。
4. 按本次特征检索自动化踩坑知识库。
5. 动手或向用户提问前，先查云端记忆、本地笔记、本项目知识库。三处已写明的不再问用户。
6. 开工结果分两栏：可作预期依据（只收已确认，带编号和链接）；只作背景（待确认、可能过期、未命中，不用来判通过或失败）。不把「非已过期」当规则读入。

## 第三步：三句复述
写满这三句，缺一句视为未开工：
1. 范围：（）
2. 验收依据：（已确认编号 + 要点原句，或资料页，或「无依据，停」）
3. 禁做：（）

用户在本聊天：用上面的固定短句问清再动手。其他机器人派的工，缺项先向派工方核对；用户决策仍只认用户当轮原话。

三句写满后，按派工与接单记「已接单」。还没记之前，这单仍在待接。

代理和有头按 [box-ui-speed](sand-workflow:box-ui-speed)。需要提醒用户时，仍在开工前提醒并写明原因，没提醒不得开工。不在这里重写例外情形。不改平台网络和浏览器配置。

UI 默认无头、直连、不开平台浏览器。只有直连已证实不通、必须用保险库填表、或用户要接手时，才走代理或开平台浏览器，并且开工前必须先在当前聊天提醒用户并写明原因，没提醒不得开工。不改平台网络和浏览器配置。测试执行不抢、不驱动平台桌面浏览器；改脚本复用已打开的页面和登录态，不要每次重新开页面。细则见 [box-ui-speed](sand-workflow:box-ui-speed)。
