# 常驻规则包

各账号共用这一份。只在约定对话里改，读回后开拉取请求。其他账号只对照版本安装，不另写一份。未合并进 Git 前，不按这一版安装。

根上 `AGENTS.md` 只写仓库怎么跑。本文件不抄它，也不抄技能全文。规则管常守短约定。按步骤做的活读 `grokbot/cursor-resident/skills/`。仓库里的 `grokbot/skills/` 是机器人技能脱敏副本，只供对账，不要当成 Cursor 专用技能安装。

## 正本

- 协作规矩和可提交的改动：Git。本文件是协作规矩正本。
- 用例、业务知识、缺陷、测试日志：该项目 Notion 知识库。项目需求用例仍以 Notion 用例库为准。
- 共用踩坑：Notion「01 共用方法」下「共用踩坑库」。
- 表和工作台：谷歌表。工作台对话对应关系只在「QA机器人Cursor工作台」本账号那一页。地址见同步总表与本机指针。不把对话链接写入 Git 或本文件。
- 周备份：谷歌硬盘`QA机器人备份/<账号名>`。各账号周包不复制规则包或技能正文。
- 临时图片、视频、安装包、压缩包，以及走查摘录：硬盘根目录「QA临时文件」。满 3 天未改，进回收站。
- 测试账号正本：本机、谷歌表「测试账号-完整库」、Notion「测试账号」。先本机，再查完整库。「测试账号-给人看」不是查密文的第一来源。

Cursor 平时直接拉 Git 最新来用，不必先去硬盘找。Cursor 自带的对话保存和已提交规则继续用。它们不当用例、知识或周包的正本。

## 短约定

1. 正本在哪：规矩在 Git，用例和知识在 Notion，表和工作台在谷歌表，临时文件在「QA临时文件」，周包按账号目录放。
2. 走查正式清单读本机 `walkthrough/cases.md`，并在「QA临时文件」放一份 Cursor 能打开的摘录。派单写明文件名和站点章节。带密文的清单不推进 GitHub。
3. 测的过程中按编号走，遵守当次禁做，边测边留证据。结论只许：通过、失败、阻塞、未测、未验证。
4. 测完先出当次报告，再把已打开、页面稳定、有判定信号的项收成可回归脚本，覆盖接口、UI，以及其他能提高回归效率的脚本。脚本必须带能红能绿的断言。生产上禁止提交的操作，脚本里也不做成会提交的步骤。
5. 账号、密码、token：Grok Bot 聊天里不写。其他地方为了测得快可以放，包括本机账号本、完整库、Notion「测试账号」、QA临时文件、本机留痕、当次报告和结论包、交给 Cursor 的摘录。会推到 GitHub 的仓库文件里仍不写明文，改用环境变量，或从本机、临时文件读取。
6. 找不到账号时，按当次任务允许的方式去云端找、前台注册或后台建号，不要卡住，也不要编造密码。当次任务没有允许这些方式时，停并说明缺账号。
7. 能复用的操作或测试用例都要写成复用脚本，脚本要边测边改。UI 用例和接口用例注明哪些走 UI、哪些走接口。

工作台怎么查、怎么续聊：打开谷歌表「QA机器人Cursor工作台」里`工作台-<当前账号>`。同一机器人、同一项目的常驻对话接着聊。对话打不开、已过期或无法继续时，旧行改为停用，记上一条，再开新对话。不把来源账号的页当成当前号去续聊。同步时核当前账号每个机器人应有的工作台，核实缺失的按 `grokbot/BACKUP.md` 补上。不把对话链接写入 Git。

阻塞告诉总控。不在这里重写派工流程。

## 去哪读

- 找出处：读同步总表，按类型和范围过滤，不读整表。
- 查号、写号：技能「测试账号云端同步」。
- 打周包：`grokbot/BACKUP.md`。账号周包不复制本规则包和专用技能正文。共享资料快照见该文件，本文件不另抄。
- 对话对应哪个机器人：查、写当前号时看`工作台-<当前账号>`。同步时用来源账号的页对照，见 `grokbot/BACKUP.md`「恢复与同步检查清单」。
- 仓库怎么跑：只读根上 `AGENTS.md`。
- 按步骤做的测试、写库、探路、写脚本：读 `grokbot/cursor-resident/skills/` 里同名技能。
- 用例设计：读 `grokbot/cursor-resident/skills/case-design/SKILL.md`。规则与 `grokbot/skills/case-design/SKILL.md` 同一句。
- 需求分析：读 `grokbot/cursor-resident/skills/requirement-analysis/SKILL.md`。规则与 `grokbot/skills/requirement-analysis/SKILL.md` 同一句。
- 用例评审：读 `grokbot/cursor-resident/skills/case-review/SKILL.md`。已用新名「用例评审」，目录仍是 case-review；旧名「用例复核」以本技能为准。规则与 `grokbot/skills/case-review/SKILL.md` 同一句。
- 换号、换机器，或把一个账号的工作台同步到另一个账号：读 `grokbot/BACKUP.md`「恢复与同步检查清单」。核当前账号每个机器人应有的工作台，核实缺失的补上并读回。Git 拉完不算同步完成。

## 硬盘镜像

谷歌硬盘「QA机器人备份/cursor-pack/qa-agent-team/」只做自动镜像，不是日常入口，也不在硬盘上改正文，不另打 zip。

例程把 Git 最新拉到该目录后，必须核对两件事：镜像里的提交号与 Git 当前提交号一致，并且 `PACK.md` 首行版本与 Git 里该文件首行一致。对不上就不能当成已同步，先重拉或停下告诉总控。

各账号自己的周包仍只放该账号的记忆、例程和对话映射快照，不和这份共用镜像混在一起。

## 版本

版本只写在本文件首行。已装版本记在该账号的本机指针里，一行，不进 Git。安装和升级步骤见同目录 `INSTALL.md`。

已装版本等于本文件首行：立刻停止。不改指针，不写 Notion，不写硬盘，不重装技能。

没有已装版本，或低于本文件首行：按 `INSTALL.md` 安装。装完只把本机指针里的版本改成首行版本。未合并进 Git 的预览不算已安装。

## 新账号初始化

1. 拉取 qa-agent-team 的已合并版本。
2. 读本文件首行，再读本机指针里的已装版本。地址见同步总表与本机指针。
3. 版本相同就停，什么都不写。
4. 版本缺失或更低，才按 `INSTALL.md` 安装，并只更新本机指针里的版本。
5. 连接器要用户重新授权。授权、登录态、Cookie 不能从周包或硬盘镜像恢复。
6. 需要本账号的记忆和例程时，只打开`QA机器人备份/<本账号名>`里最新周包，按包内 `RESTORE.md` 贴回。不把来源账号的记忆贴回本账号。同步工作台时读来源账号目录的最新完整包和较新的增量包或 skill-sync 包，步骤见 `grokbot/BACKUP.md`。
7. 规则包和 `AGENTS.md` 以刚拉下来的 Git 为准。工作台以谷歌表本账号页为准。镜像只在 Git 或该表暂时拿不到时对照，不覆盖仓库，也不覆盖表里更新的映射。

## 何时写到哪

只有任务本身产生了对应产物才写。

- 规矩、代码、专用技能：Git 新分支，打开拉取请求，等人审核。生成后先读回。会推到 GitHub 的文件不写明文账号、密码、token。
- 用例、知识点、缺陷、当日测试记录：该项目 Notion 知识库。不写进本文件，不写进周包。
- 可复用踩坑或已验证解法：当时写入共用踩坑库，先按现象指纹去重。不另建可编辑的谷歌文档。
- 账号变更：走「测试账号云端同步」。Grok Bot 聊天不写密文。在用户点头把 Notion「测试账号」共享给 Cursor 之前，Cursor 不直接改账号正本。
- 工作台对应关系有变化：先改谷歌表本账号页，再使用那条对话。不写进 Git。
- 周备份：每周日，由该账号总控按 `BACKUP.md` 写入`QA机器人备份/<本账号名>`。不每日打。旧包改名已替换，不删除。不把规则包和专用技能正文打进账号周包。
- 临时文件：放「QA临时文件」。文件名要能分清是谁的、干什么用的。不从回收站找回来当正本。

同一 Cursor 账号上的云端对话，续聊就是同步。不把对话正文再导出成第二正本。个人偏好可以留在这个 Cursor 账号的 User Rules。和本文件冲突时，以本文件为准。

## 怎样避免打架

每类内容只有一个正本。正本还在，就不用镜像、快照、回收站或其他账号的副本覆盖它。

- 常驻规矩听已合并进 Git 的本文件。硬盘镜像、User Rules、未合并分支、云电脑上未提交的文件都让路。镜像提交号或首行版本对不上，不当已同步。
- 工作台听谷歌表里当前账号那一页。周包里的表快照让路。不在 Git 另做映射。同步时读来源账号那一页作对照，不把来源页当成当前号。核实缺失的工作台补在当前账号页，见 `grokbot/BACKUP.md`。
- 对话正文听同一 Cursor 账号下的原对话。
- 机器人技能听现网。`grokbot/skills/` 和周包快照只供对账。Cursor 执行听 `grokbot/cursor-resident/skills/` 里已合并的版本。
- 用例和知识听该项目 Notion。共用踩坑听共用踩坑库。
- 测试账号听本机、完整库、Notion「测试账号」。临时文件和周包不是正本。
- 记忆和例程只恢复`QA机器人备份/<本账号名>`里最新周包。其他账号不对倒。

几个账号如果连着同一个谷歌账号，仍然只改自己的备份子目录和自己的工作台页。不改、不删其他账号的子目录。读来源目录是为了核当前账号的工作台。不把来源账号的记忆和技能写进当前账号，也不写回来源目录。

云电脑磁盘快照闲置超过 30 天会清除。恢复对话和规矩都不依赖快照。
