# 常驻规则包

各账号共用这一份。只在约定对话里改，读回后开拉取请求。其他账号只对照版本安装，不另写一份。未合并进 Git 前，不按这一版安装。

根上 `AGENTS.md` 只写仓库怎么跑。本文件不抄它，也不抄机器人技能全文。技能按名字去读 `grokbot/skills/`。

## 正本

- 协作规矩和可提交的改动：Git。本文件是协作规矩正本。
- 用例、业务知识、缺陷、测试日志：该项目 Notion 知识库。
- 共用踩坑：Notion「01 共用方法」下「共用踩坑库」。
- 周备份：谷歌硬盘「QA机器人备份/<账号名>」。
- 临时图片、视频、安装包、压缩包：硬盘根目录「QA临时文件」。满 3 天未改，进回收站。账号密码的临时副本可以放这里，正本仍是本机、谷歌表「测试账号-完整库」、Notion「测试账号」。
- 工作台对话对应关系：谷歌表「QA机器人Cursor工作台」里本账号那一页。地址见同步总表与本机指针。不把对话链接写入 Git 或本文件。
- 测试账号查写：技能「测试账号云端同步」。先本机，再查完整库。给人看的表不是查密文的第一来源。

Cursor 自带的对话保存和已提交规则继续用。它们不当用例、知识或周包的正本。

## 去哪读

- 找出处：读同步总表，按类型和范围过滤，不读整表，不把整表抄进记忆。
- 查号、写号：只走「测试账号云端同步」。
- 打周包：只走 `grokbot/BACKUP.md`。
- 对话对应哪个机器人：只查工作台谷歌表的本账号页。
- 仓库怎么跑：只读根上 `AGENTS.md`。

## 版本

版本只写在本文件首行。已装版本记在该账号的本机指针里，一行，不进 Git。

已装版本等于本文件首行：立刻停止。不改指针，不写 Notion，不写硬盘，不写记忆，不重装技能。

没有已装版本，或低于本文件首行：按 `grokbot/HANDOFF.md` 安装技能，按花名册核对机器人。在「QA机器人备份」下如果还没有与本账号同名的子目录，就新建。装完只把本机指针里的版本改成首行版本。

## 新账号初始化

1. 拉取 qa-agent-team。
2. 读本文件首行版本，再读本机指针里的已装版本。地址见同步总表与本机指针。
3. 版本相同就停，什么都不写。
4. 版本缺失或更低，才按上一节安装，并只更新本机指针里的版本。
5. 连接器要用户重新授权。授权、登录态、Cookie 不能从周包恢复。
6. 需要本账号的记忆和例程时，只打开「QA机器人备份/<本账号名>」里最新周包，按包内 `RESTORE.md` 贴回。不打开其他账号的子目录。
7. 规则包和 `AGENTS.md` 以刚拉下来的 Git 为准。工作台以谷歌表本账号页为准。周包里的镜像只在 Git 或该表暂时拿不到时对照，不覆盖仓库，也不覆盖表里更新的映射。

## 何时写到哪

只有任务本身产生了对应产物才写。

- 规矩、代码、技能脱敏副本：Git 新分支，打开拉取请求，等人审核。生成后先读回。不写进 User Rules，不写进 Saved Memories，不在硬盘上另改一份正文。
- 用例、知识点、缺陷、当日测试记录：该项目 Notion 知识库，沿用现有写库和读回。不写进本文件，不写进周包。
- 可复用踩坑或已验证解法：当时写入共用踩坑库，先按现象指纹去重。不另建可编辑的谷歌文档。
- 账号变更：走「测试账号云端同步」。聊天、Git、本文件、周包都不写密文。在用户点头把 Notion「测试账号」共享给 Cursor 之前，Cursor 不直接改账号正本。
- 工作台对应关系有变化：先改谷歌表本账号页，再使用那条对话。不写进 Git。
- 周备份：每周日，由该账号总控按 `BACKUP.md` 写入「QA机器人备份/<本账号名>」。不每日打。旧包改名已替换，不删除。
- 临时文件：放「QA临时文件」。文件名要能分清是谁的、干什么用的。不进本文件，不进知识库，不从回收站找回来当正本。

同一 Cursor 账号上的云端对话，续聊就是同步。不把对话正文再导出成第二正本。个人偏好可以留在这个 Cursor 账号的 User Rules。和本文件冲突时，以本文件为准。

## 怎样避免打架

每类内容只有一个正本。正本还在，就不用镜像、快照、回收站或其他账号的副本覆盖它。

- 常驻规矩听已合并进 Git 的本文件。周包镜像、User Rules、未合并分支、云电脑上未提交的文件都让路。
- 工作台听谷歌表本账号页。周包里的表快照让路。不在 Git 另做映射。
- 对话正文听同一 Cursor 账号下的原对话。
- 机器人技能听现网。Git 脱敏副本和周包快照只供对账。对不上时以现网为准，再把脱敏副本补回 Git。
- 用例和知识听该项目 Notion。共用踩坑听共用踩坑库。周包导出只是快照。
- 测试账号听本机、完整库、Notion「测试账号」。临时文件和周包不是正本。
- 记忆和例程只恢复「QA机器人备份/<本账号名>」里最新周包。其他账号不对倒。

几个账号如果连着同一个谷歌账号，仍然只改自己的备份子目录和自己的工作台页。不进、不改、不删其他账号的子目录。

云电脑磁盘快照闲置超过 30 天会清除。恢复对话和规矩都不依赖快照。
