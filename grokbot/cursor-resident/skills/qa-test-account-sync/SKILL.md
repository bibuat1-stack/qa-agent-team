# 测试账号云端同步

产物是三处正本是否一致。不用于派活，不用于写业务知识库。项目暂停时仍可读写账号正本，但不因此开工。

## 停手

问不清项目、系统或账号别名时，只问：「要查或改的是哪个项目、哪个系统、哪个账号？」

Grok Bot 聊天不写密码、谷歌密钥、验证码、token。用户要看密码时，只给页名「测试账号」、表名和「见同步总表与本机指针」。

没有用户当轮原话，不改本机已有行，不改旧表「各项目测试账号与凭证」。

本机、完整库、Notion 读回不一致，保持未完成，不把其中一处当成已同步。

当次任务没有允许找号、注册或建号，并且本机和完整库都没有可写回的账密：停。写「本机和完整库都没有这个账号，停。」不跨项目借用，不编造密码。

不把完整库里的全部账号堆进「测试账号-给人看」。

## 正本

地址见同步总表与本机指针。不在本技能写窗口路径或表链接。

- 本机账号文件
- 谷歌表「测试账号-完整库」，按项目分工作表
- Notion 页「测试账号」

查找顺序：先本机，没有再查完整库。Notion 是同步写入处，不是查找第一来源。

「测试账号-给人看」每域名最多 3 条，用户给的主号优先，不是查密文的第一来源。

本机和 Notion 用同一套列：环境、系统、域名、账号、密码、谷歌密钥、保险库登录名、用途、更新日期。环境名按本项目知识库已确认叫法写。

## 查找

1. 按项目、系统、环境、账号别名在本机定位。
2. 本机没有，再查完整库对应项目表。不要只在给人看的表里查缺。
3. 账号、密码、谷歌密钥齐全：在当前任务里使用。会推到 GitHub 的文件不写明文，从本机或「QA临时文件」读取。
4. 没有或不全：当次任务允许时，按允许的方式去云端找、前台注册或后台建号，然后立刻写回三处并读回。不允许时停。不编造密码。

## 增加或更新

1. 先读三处现有行再合并。没有用户当轮原话要求删除的非空字段，不准用空值覆盖。
2. 谷歌密钥图片在本机解码后写入「谷歌密钥」。解不开就停。不把密钥写进聊天。
3. 人给的账号：先写本机，再写完整库，再写 Notion「测试账号」，再按规则更新给人看的表。
4. 大批量生成的测试账号只写本机和完整库，不写入给人看的表。
5. 写谷歌表时按字面写入，避免把加号和乘方符号当成公式。
6. 写 Notion 时，密文放在本机临时文件里代入，不写进会留下明文的调用文本。写完删除临时文件。
7. 写完按原路径、原页名、原表名再读一次。比较前去掉 Notion 可能加上的转义。本机未转义的值是基准。
8. 三处的账号、密码、谷歌密钥、用途一致，才算完成。不一致只报告哪一处哪一列对不上，不写值。

## 填写

项目、系统、环境、账号别名、动作（查找、新增或更新）、更新了哪些列名、是否批量生成、三处读回是否一致、给人看的表是否按规则更新、结论。不填密文。
