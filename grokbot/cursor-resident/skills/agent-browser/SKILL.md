# agent-browser

备用。优先级按 box-ui-speed：有接口用接口；可重复回归跑仓库脚本；网页探路默认 playwright-cli。本工具不混抢同一测号。

它启动的是独立浏览器，不是平台桌面那扇窗。不要用它去驱动平台桌面浏览器。

## 使用前

先确认命令可用。用法以当前安装的命令自带说明为准，不抄过期文档。每个任务用独立会话。

## 循环

打开地址，抓可交互快照，按引用点击或填写，看请求，结束关闭会话。导航后重新抓快照。同一步失败两次就停。

登录仍按测试账号云端同步。密码不进聊天，不进会推到 GitHub 的文件。

它的轨迹不是路径留痕。需要路径留痕的探路改回 playwright-cli。跑通后仍要落成仓库脚本，第二次起不再用本工具手点。
