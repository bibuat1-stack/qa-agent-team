# 复现缺陷

用于界面和交互问题。纯后端问题除非任务明确要求看见画面，否则不用本技能。

## 最小步骤

1. 记现象：错误、时间、路由或命令、最小输入。二手描述标未证实。
2. 记环境：只写查到的。不猜凭证和生产配置。
3. 期望和实际各写一句可观察的话。不把猜因写进去。
4. 按报告路径走，再逐项去掉无关步骤。失败消失就恢复最后去掉的条件并记下。
5. 安全时至少跑两次。偶发写频率，不谎称必现。
6. 这一步的交付是简报，不改产品代码。

简报栏：目标、环境、期望、实际、最小步骤、必现或大约几次里的几次、证据位置、未证实、下一步只写一条。

## 执行

路径清晰就探路一次。多个假设分次做，不并行抢同一测号。探路默认 playwright-cli，见 box-ui-speed。缺凭证或授权环境拿不到时，直接报阻塞，不猜。

全部做完再汇总：确认、部分确认、未复现、阻塞。外发证据走 evidence-hygiene。本机留痕按测试证据留原文。
