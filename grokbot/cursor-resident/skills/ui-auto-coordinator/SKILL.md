# 共用踩坑

本技能不探路，不写脚本，不连跑，不替项目做业务测试。探路见 box-ui-speed。手测转脚本见 automation-regression。

正本是 Notion「01 共用方法」下「共用踩坑库」。不另建可编辑的谷歌文档。

## 怎么写

每条只写：问题、改法、结果、仍未证明什么，加上项目、类型、现象指纹和证据位置。现象指纹等于类型加范围加对象加一句现象，不含日期、账号、对话。

不要把一次试跑写成全队有效。还没验证的写未解决或仍未证明，不写成结论。新条默认待验证。

禁止写入凭证和授权头。外发前走 evidence-hygiene。业务规则不进踩坑库，回本项目知识库。

## 去重

先按指纹检索。命中未解决就追加，不新开。命中已验证解法且仍然有效，不新开，回报写原标题。已验证解法这次无效，新开未解决条并关联旧条，旧条不动。写完按原标题读回。

已验证正文只许原写入者或当前在用账号的总控标成被替代。不删原文。

## 框架

框架方案先在本仓库的审查里通过，再改代码。未审不改生产配置。本技能不替执行方连跑。
