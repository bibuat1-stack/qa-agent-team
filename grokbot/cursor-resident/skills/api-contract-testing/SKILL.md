# 接口契约测试

验证请求和响应的形状、状态码和字段约定。不扩大授权。

## 步骤

1. 找到本项目权威契约：接口说明、集合或知识点里的字段表。地址见同步总表与本机指针。找不到就写「未找到契约」，不编字段。
2. 对关键路径断言必填字段、类型、枚举和错误码。
3. 单独列出破坏性变更：删字段、改类型、收紧枚举、改状态码含义。
4. 预期必须能指到契约或已确认知识点。无依据标待确认。
5. 能先做接口冒烟就先做接口。界面只覆盖契约盖不住的呈现和状态。

凭证从本机或环境变量读取。不写进会推到 GitHub 的文件，不写进 Grok Bot 聊天。

## 输出

通过、失败或未跑；契约来源的名称；破坏点列表；证据位置。不在对外正文里写明文凭证。
