# Playwright 报告分诊

只处理本项目这一跑的产物。找不到报告就写「未找到报告」，不要猜。

## 打开顺序

1. 本跑次 HTML 报告。
2. 失败用例的轨迹包。
3. 失败截图和错误上下文。
4. 已有的接口摘要。外发前的摘要按 evidence-hygiene 处理。本机留痕可以留原文。

## 步骤

1. 记下用例名、浏览器、重试次数、最终状态。
2. 区分断言失败、超时、选择器丢失、页面崩溃。
3. 有请求记录时，看关键请求是不是先失败。
4. 对比前后截图：没点到，还是点到了后端错。
5. 重试里曾经通过：标不稳定候选，附次数，不直接当通过。

## 结论标签

只用这些：前端或选择器、接口或契约、环境或账号或权限、用例或期望无依据、不稳定、证据不足。

输出短句：结论标签、失败用例、直接证据位置加一句、接口是否先失败、建议下一刀、没打开的附件。无证据不算测过。缺陷候选先按测试证据过滤，再入库。
