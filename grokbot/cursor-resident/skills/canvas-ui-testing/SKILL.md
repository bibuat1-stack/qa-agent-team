# 画布页面

普通页面走 ui-interaction-kit。先读结构树。目标区域只有画布、读不到按钮名字，才用本技能。外壳上的按钮和输入框仍按结构树。

## 从稳到不稳

1. 画面上的数先找接口或实时帧。结论以数据为准，画面只确认显示一致。
2. 测试环境若已有场景树或调试对象，按普通页面定位。问到的结果记进知识库，标待确认。不自己注入脚本改状态。
3. 固定视口、缩放、语言和时区。热区用相对画布左上角的比例，不记屏幕绝对坐标。点击前先截该区域。
4. 小图比对找不到就报失败加截图，不把阈值降到能过为止。
5. 截图对比要遮住时间、余额、动画。只有差异区域再看。
6. 看整图只算疑似。没有前五项里至少一项佐证，不写通过或失败。

等画面稳定再截。只截要看的区域。白屏或半截先怀疑没等够，如实报，不重试成通过。

每次点击记热区名、比例、前后截图、比对结果。基准图按视口和日期另存，不覆盖旧基准。不改游戏代码，不改平台桌面浏览器。
