# 浏览器走查

对已授权的测试环境做冒烟和交互核对。正式可重复路径以仓库脚本为准，并加载 automation-regression。探路见 box-ui-speed。

目标地址必须是本项目已授权环境。不确定就停。

## 边界

默认只读。充值、提现、下注、领奖、绑卡、删数、生产真实资金写入禁止。生产上禁止提交的操作这里也不做。

外发截图和抓包按 evidence-hygiene。本机留痕和当次报告按测试证据留原文。

## 冒烟

打开目标。看控制台里本项目的关键错误，滤掉无关第三方噪音。看关注接口有没有四字头或五字头。留首屏截图。没有性能工具就标未测，不编指标。

## 交互

主导航和关键入口按当次编号走，不擅自扩测。表单的有效输入和无效输入都要有依据才写期望。登录只用当次测号。

## 视觉

按任务需要的宽度截图。没有基线就写「无基线，无法视觉对比」，禁止静默写通过。明显溢出、缺控件、错位记缺陷候选，先按测试证据过滤。

## 结论

只许：通过、失败、阻塞、未测、未验证。每条挂证据位置。无证据不算测过。
