# 界面交互

不跨项目借账号或入口。探路工具只按 box-ui-speed，默认 playwright-cli 的快照。不在这里并列三套工具。

## 读页面

1. 先读无障碍树：按钮、输入框、对话框、列表、表格的角色和可访问名。
2. 其次用测试标识、稳定 id 或 name。避开易变类名和纯坐标。
3. 看禁用、忙碌、展开、隐藏、加载这些状态。
4. 像素和识图只作兜底，而且要有可点与不可点的对照。普通页不要猜像素。
5. 读不到按钮结构的画布区域改走 canvas-ui-testing。外壳上的按钮仍按结构树。
6. 有接口时同时看请求，区分展示问题和接口问题。

## 操作

大页先按文案查找节点。需要位置时让快照带框，点的时候仍用引用、角色或测试标识。必须看画面时再配一张页面截图，把目标标出来对照，不把标记留在被测页上。

跑通后当场生成定位器，落成角色或测试标识脚本。

操作后必验：按钮点完看约定的状态或请求；弹层打开后能找到标题或关闭；表格先等数据请求再对单元格。判定信号中途不换成更弱的。没有信号写未验证。
