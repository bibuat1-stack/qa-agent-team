# 证据脱敏

只用于外发、发给开发或写入聊天之前。本机留痕、当次报告和结论包按测试证据留原文，不在这里脱敏。

## 外发必须去掉

本账号秘密：会话 Cookie、刷新令牌、接口密钥、授权头、测号密码。一律替换成已脱敏标记。

他人的个人信息：真名、邮箱、手机、地址、人脸。默认打码。

可以保留：追踪号、请求号、时间戳、测试账号的非密码标识、接口路径和响应形状。

## 外发前检查

画面里不要留下网络头、Cookie 面板、地址栏里的令牌，或带 Cookie 的整段命令。抓包和文本里的 Cookie 和授权头先替换，再附上。未处理的标「不可外发」。

资金类截图额外看金额和真实用户标识。

Grok Bot 聊天、Notion 知识库正文、会推到 GitHub 的文件，仍不写明文凭证。本机留痕和当次报告不受这一条限制。

## 输出

列出已可外发的文件位置。未处理的单独标出，不附上。
