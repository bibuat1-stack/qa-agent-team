# 无障碍

不扩大授权。只测本项目已授权环境。凭证不写进技能和会推到 GitHub 的文件。外发证据走 evidence-hygiene。默认只读，不做资金写入。

## 工具

优先用 playwright-cli 或仓库脚本抓无障碍树、走键盘、截图。回归用无障碍快照断言钉住关键结构。有现成的自动扫描再跑；没有就标「未测自动扫描」，不编结果。画布页改走 canvas-ui-testing。

## 步骤

1. 打开目标页，抓树：名称、角色、状态、地标、标题层级。
2. 只用键盘走关键路径。焦点要看得见，不能困在组件里出不来。
3. 表单控件要有可访问名。错误提示要能被读到。
4. 对比度只在量得到的时候下结论。量不到写未测。
5. 发现写清：位置、现象、是否挡住任务、证据位置。不把一次抽检写成全站通过。

结论只用：通过、失败、阻塞、未测、未验证。
