# 安装与升级

本文件只说明 Cursor 专用包怎么按版本安装。专用技能在 `grokbot/cursor-resident/skills/`。不要安装 `grokbot/skills/`，那是机器人技能的脱敏副本，只供对账。

未合并进 Git 的预览包不能当成已安装。比较版本时，只认 Git 里已合并的 `grokbot/cursor-resident/PACK.md` 首行。

## 平时怎么用

Cursor 平时直接拉 Git 最新来用，不必先打开硬盘。硬盘上的「QA机器人备份/cursor-pack/qa-agent-team/」是例程自动镜像，不是安装入口。

## 什么时候安装或升级

1. 读 Git 里 `PACK.md` 的首行版本。
2. 读本机指针里的已装版本。地址见同步总表与本机指针。
3. 两个版本相同：停止。不改指针，不写 Notion，不写硬盘，不重装技能，什么都不写。
4. 指针里没有版本，或低于 Git 首行：才安装或升级。装完只把指针里的已装版本改成 Git 首行。不把版本号写进 Git。

升级不覆盖本机指针里的其他行，不覆盖工作台表，不覆盖账号正本，不对倒其他账号的记忆和对话。

## 安装时做的事

1. 确认当前检出的是已合并提交，而不是未合并分支或硬盘镜像。
2. 确认入口文件 `.cursor/rules/resident-index.mdc` 存在，并且 `alwaysApply` 为 true。
3. 确认 `PACK.md` 首行可读。
4. 确认 `skills/` 下每个技能目录都有 `SKILL.md`。缺一个就停，不把缺的技能写成已安装。
5. 只更新本机指针里的已装版本一行。

## 核对硬盘镜像

例程更新镜像之后，核对镜像提交号与 Git 当前提交号，并核对镜像里 `PACK.md` 首行与 Git 里首行。两处都一致，镜像才算跟上。对不上不当已同步，先重拉或停下告诉总控。不要在硬盘上改规则或技能正文。
